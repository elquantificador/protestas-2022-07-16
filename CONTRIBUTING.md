# Cómo contribuir

Gracias por querer mejorar este material.

- Abre un issue antes de enviar cambios grandes.
- Al enviar una contribución aceptas que se publique bajo las licencias del
  repositorio: MIT para el código (`LICENSE`) y CC BY-NC 4.0 para el contenido
  (`LICENSE-content`).
- No incluyas datos personales ni datos de terceros sin permiso de su titular.
- El material elaborado por practicantes y colaboradores de LIDE para El
  Quantificador pertenece a LIDE.
